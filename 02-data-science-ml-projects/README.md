# Data Science / ML Projects

End-to-end projects covering the core data science workflow — feature
engineering, model training, evaluation, and interpretation — on
synthetic data modeled after real analytics domains.

| Project | Domain | Technique |
|---|---|---|
| [`credit_risk_scorecard/`](credit_risk_scorecard/) | Consumer credit risk (ties to Wells Fargo/USAA experience) | Logistic regression scorecard + gradient boosting, ROC/AUC |
| [`customer_churn_prediction/`](customer_churn_prediction/) | General subscription/product analytics | Random forest classification, full evaluation suite |
| [`customer_segmentation_clustering/`](customer_segmentation_clustering/) | CRM / retail segmentation (ties to Kellogg's experience) | RFM feature engineering + K-Means clustering |

Each project is self-contained: run its script directly to regenerate
synthetic data, train the model, and produce the plots/CSVs described in
its own README.
