# Time-Series Forecasting

Forward-looking forecasting, distinct from the trend *reporting* used
elsewhere in this repo — the difference between describing what
happened and predicting what happens next, with an honest accuracy
check against a baseline.

| Project | What it does |
|---|---|
| [`portfolio_delinquency_forecast/`](portfolio_delinquency_forecast/) | Seasonal decomposition, a Holt-Winters forecast backtested against a naive-seasonal baseline, and a 6-month forward forecast with a confidence band |

See the repo's [`ROADMAP.md`](../ROADMAP.md) for what's planned next.
