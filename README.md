# SAS → Data Science / ML Transition

A portfolio built alongside a 12-year SAS/SQL career transitioning into
Data Science and Machine Learning. Every project here is runnable and
verified, not just described — the goal is to demonstrate the transition
directly rather than claim it on a resume.

## Background

12 years as a SAS/SQL analyst across financial services (Wells Fargo,
USAA, Global Atlantic), retail (Kellogg's), and financial/healthcare
(GeP) — building data governance frameworks, audit/remediation programs
(DAQC), credit-risk and delinquency reporting, and CRM segmentation.
This repo documents the concrete steps of moving that skill set toward
Python, R, SQL-based analytics engineering, and AI-assisted workflows.

## Structure

```
01-sas-to-python-r-migration/   Real SAS patterns rebuilt side-by-side in Python and R
02-data-science-ml-projects/    End-to-end ML projects (classification, clustering, scorecards)
03-sql-analytics-portfolio/     Advanced SQL (window functions, CTEs) against a runnable SQLite DB
04-ai-agentic-workflows/        AI-assisted analytics tooling built with Claude
```

| Folder | Highlights |
|---|---|
| [`01-sas-to-python-r-migration/`](01-sas-to-python-r-migration/) | Roll-rate delinquency analysis and a data-dictionary generator, each implemented identically in SAS, Python, and R |
| [`02-data-science-ml-projects/`](02-data-science-ml-projects/) | A credit-risk scorecard (logistic regression + gradient boosting), a churn classifier, and RFM/K-Means customer segmentation |
| [`03-sql-analytics-portfolio/`](03-sql-analytics-portfolio/) | Window-function and CTE-based analytical queries against a synthetic lending portfolio in SQLite |
| [`04-ai-agentic-workflows/`](04-ai-agentic-workflows/) | A SAS macro documenter and a data-quality review agent, both usable standalone or upgraded with Claude |

## A note on data

Every dataset in this repo is **synthetic**, generated by a script
included alongside it (`generate_*.py` / `setup_sqlite_db.py`). No
proprietary, customer, or employer data appears anywhere in this
repository — the synthetic data is deliberately modeled on the shape and
statistical patterns of real consumer-lending and CRM data so the
analysis techniques transfer directly.

## Running any project

Each project folder has its own README with exact commands. In general:

```bash
git clone https://github.com/nnikhil785/sas-to-datascience-transition.git
cd sas-to-datascience-transition
pip install -r requirements.txt

# then, from inside any project folder, e.g.:
cd 02-data-science-ml-projects/credit_risk_scorecard
python credit_risk_model.py
```

R examples additionally require R installed (`Rscript`); SAS examples
are included as reference source only and require a licensed SAS
environment to execute.

## Why this structure

Recruiters and hiring managers reviewing this repo for a Data
Analyst/Scientist role can see, in order: (1) the exact migration from
the SAS skill set already on the resume, (2) applied ML fundamentals,
(3) SQL depth, and (4) practical experience integrating AI tools into
real analytics workflows — matching the four things most Data
Science/ML job postings ask for.
